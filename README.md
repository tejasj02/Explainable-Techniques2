# Explainable-Techniques2

This repository conducts EDA and feature analysis on a health dataset found here https://www.kaggle.com/datasets/minahilfatima12328/lifestyle-and-sleep-patterns. A random forest model was created to evaluate feature importance over a select set, specifically looking at PDP, ICE, and ALE plots.

To run the notebook, please install the required packages via

```
pip install -r requirements.txt
```

and then proceed cell by cell.
